SauceDemo Test Automation

  • Java
  • Selenium WebDriver
  • Page Object Model

What it is

An automated regression suite written against SauceDemo, a demo e-commerce site built for practising UI automation. It covers the flows a real store depends on: logging in, filtering the catalogue, adding items to a basket and completing checkout.

Why I built it

My day job runs on a client codebase I cannot show anyone. This is the equivalent work in public, somewhere I can demonstrate how I structure a suite rather than just claim I can.

How it is put together

Each page of the application has its own class holding its locators and the actions available on it, so a change to the markup is fixed in one file rather than across every test. Tests describe behaviour and read as behaviour; the selectors stay out of them.

The negative cases are the interesting ones: locked-out users, wrong credentials, empty baskets at checkout. Those catch more real regressions than the happy path does.

Status

In progress. The repository is private while I build it out, and will be public once the suite is complete.
