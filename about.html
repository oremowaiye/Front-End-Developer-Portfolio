About

I test software for a living and I'm studying security alongside it. Both come down to the same instinct: working out how something breaks before someone else finds out.

I started in web development, with a software development bootcamp, then freelance front-end work and a web management role. That background turned out to be the useful part of testing. Knowing how an application is put together makes it much easier to work out where it will fall over, and to write tests that survive the next release.

I moved into test automation in 2024 and have been working in Java and Selenium since. The MSc came after: security testing is where the two interests meet, and it's the direction I want to take.
