FilmFlix Database

  • Python
  • SQL
  • SQLite

What it is

A command-line application for managing a film catalogue. It handles adding, searching, updating and removing records, with the data held in a relational database rather than in memory.

What it involved

Designing the table structure, writing the queries behind each menu option, and validating input before it reaches the database. It was where SQL stopped being exercises for me and became something I used to build a working thing.
