What it is

The site you are reading. Hand-written HTML and CSS with no framework and no build step, deployed on Netlify from GitHub.

Why it is plain

A portfolio that needs a toolchain to render four pages of text is solving a problem it does not have. Static files load instantly, cost nothing to host and will still work in five years. The CSS is a single stylesheet using custom properties, which is also what makes the dark mode a few lines rather than a second theme.
